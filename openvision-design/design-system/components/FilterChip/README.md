# FilterChip

Чип фильтра ленты событий: камера, «Известные/Неизвестные», период.

- Ряд чипов прокручивается горизонтально (`ov-chips`), над лентой, под шапкой.
- Выбранный: `brand-soft`, рамка и текст `brand`, галочка. `menu` — чип открывает шит выбора (камеры, даты).
- `count` — число событий, если оно известно без лишнего запроса.
- При смене фильтра сбрасывайте курсор и грузите первую страницу.
