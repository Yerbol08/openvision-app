# Icon

Набор линейных иконок 24×24, обводка 1.75, скруглённые концы; цвет — `currentColor`.

- Размеры: 20 в строках и полях, 22 в навигации, 16 в чипах и бейджах.
- Иконка без подписи рядом получает `label` (озвучка TalkBack/VoiceOver).
- Во Flutter — тот же стиль: линейные иконки, обводка ~1.75.
