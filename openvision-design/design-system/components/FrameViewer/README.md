# FrameViewer

Полный кадр события с рамкой лица.

- `bbox` = `[x, y, w, h]` в пикселях исходного кадра; компонент переводит в проценты от `naturalWidth/Height`, поэтому рамка верна при любом размере экрана.
- Рамка `scan` 2px с тёмной окантовкой `scrim` — видна на любом кадре; подпись рамки — `on-scan` на `scan`.
- Время поверх кадра — `timecode` на `scrim`.
- Двойной тап — увеличение. Не сохраняйте кадр в галерею; на экране включайте `FLAG_SECURE`.
