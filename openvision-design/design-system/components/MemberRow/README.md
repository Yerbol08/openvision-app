# MemberRow

Строка участника на экране «Команда» (только с `users.read`).

- Роль — бейдж: владелец/администратор — `brand`, оператор/наблюдатель — нейтральный. У владельца замок: его нельзя менять (`owner_protected`).
- `editable` — меню «⋮» (сменить роль, отключить, удалить); не показывайте его у владельца и у себя (`self_protected`).
- Отключённый (`is_active: false`) — приглушён, «Отключён» перед почтой.
