# StatusReason

Объяснение `status_reason` — главное, что спасает от звонка в поддержку. У каждой причины свой заголовок и текст.

- Тон: `warn` — клиенту надо подождать/проверить (`waiting_for_video`, `edge_agent_offline`); `danger` — клиент должен что-то исправить; `info` — проблема на нашей стороне (`waiting_for_gpu`, `ingest_error`), без тревоги.
- `lastSeen` для `no_video`: «Последний сигнал 3 ч назад».
- `compact` — одной строкой внутри CameraCard; полный вариант — на экране камеры, с `action` («Изменить адрес», «Подключить через блок»).
- Неизвестная причина: «Камера не работает. Обратитесь в поддержку.» и код в лог.
- Тексты в бандле — русские; казахские держите в тех же ключах ARB.
