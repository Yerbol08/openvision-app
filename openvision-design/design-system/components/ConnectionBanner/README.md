# ConnectionBanner

Полоска состояния live-соединения (WebSocket `/live`) под шапкой ленты и обзора.

- `live` — короткая подтверждающая строка; можно показывать 2 с после подключения и прятать.
- `reconnecting` — пока идёт бэкофф 1→30 с. Не блокирует экран.
- `offline` — нет сети: данные из кэша, кнопка «Повторить».
- После переподключения заново грузите `GET /cameras` и первую страницу `GET /events`, сливая по `id`.
