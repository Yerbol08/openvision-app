# ModeOption

Вариант ответа в мастере «Как подключена камера?» — вместо названий режимов pull/push/edge.

- Первый экран мастера — вопрос и три `ModeOption`. Порядок: «Только в локальной сети» (edge, большинство клиентов, тег «Чаще всего»), «Регистратор умеет отправлять поток» (push), «У камеры есть адрес в интернете» (pull).
- Выбранный: `brand-soft`, рамка `brand`, радиокнопка. Кнопка «Далее» снизу, активна после выбора.
