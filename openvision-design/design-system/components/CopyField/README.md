# CopyField

Значение, которое нельзя перепечатывать: SRT/RTSP-адрес push, stream key, команда установки edge-агента.

- Моноширинный шрифт, перенос по любому символу, кнопка «Копировать» → «Скопировано» 1,6 с.
- Рядом на экране — «Поделиться» (системный шит) и предупреждение: «Покажем только один раз».
- `badge` — «Рекомендуем» у SRT.
- Это пароли от чужого видеонаблюдения: не логируйте, не отправляйте в аналитику и крэш-репорты.
