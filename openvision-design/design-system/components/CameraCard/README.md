# CameraCard

Карточка камеры в списке: превью, имя, место, время последнего события, статус и при сбое — причина.

- Превью — кадр последнего события (`frame_url`), пока нет live-снимка; нет кадра — заглушка `media`.
- `canControl` (есть `cameras.control`) — переключатель вместо шеврона; тап по карточке — экран камеры.
- Причина (`StatusReason compact`) показывается для всех статусов, кроме `online` и `disabled`.
- Имя одной строкой с многоточием; место и время — `caption` в `ink-muted`.
