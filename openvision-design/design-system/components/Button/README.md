# Button

Кнопка действия; на экране одна `primary` — главное действие («Войти», «Сохранить камеру», «Пригласить»).

- `primary` — заливка `brand`, подпись `on-brand`. Не больше одной на экран/шит.
- `secondary` — второстепенное («Проверить подключение», «Отмена»).
- `ghost` — действие в тексте или в шапке («Показать все»).
- `danger` — только для необратимого («Удалить камеру», «Удалить пользователя»), всегда с подтверждением.
- `loading` — пока идёт запрос; проба камеры длится до ~12 с, кнопка показывает спиннер, рядом подпись «Подключаемся к камере…».
- Высота `control-h` (48), компактная `control-h-sm`. В формах и шитах — `block`.
- Подписи — глагол в инфинитиве, с заглавной: «Добавить камеру». Не скрывайте действие без права: не рисуйте кнопку, если нет нужного `permissions`.

Потребитель передаёт: `children`, `onClick`, `variant`, `loading`, `disabled`.
