# EventRow

Строка ленты событий: кроп лица, известный/неизвестный, камера, время, уверенность.

- Кроп 56×56 (`thumb-face`), `radius-xs`; `crop_url = null` — силуэт-заглушка. Кэш по `event.id`, не по URL.
- Известный: бейдж `brand` с процентом (`confidence`), когда появится `/persons` — имя вместо «Известный человек». Неизвестный: нейтральный бейдж «Новый».
- `isNew` — точка `scan` у событий, пришедших по WebSocket, пока экран открыт.
- `seenToday` — «сегодня 4 раз» по `person_id` (и для неизвестных).
- Время — локальное, `tabular-nums`; дата — в заголовке группы («Сегодня», «Вчера», «27 октября»).
