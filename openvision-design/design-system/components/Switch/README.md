# Switch

Переключатель включения камеры (`PATCH enabled`).

- Показывайте, только если в `permissions` есть `cameras.control` (оператор и выше). Наблюдателю — только бейдж статуса.
- Включённый: трек `brand`, бегунок `on-brand`; выключенный: рамка `line-strong` (3:1).
- Переключение оптимистичное: сразу меняйте вид, при ошибке откатывайте и показывайте тост.
- Всегда с подписью или `aria-label` («Камера включена»).
